# v3.0.0-alpha.2 候选报告

## 状态

本地 `3.0.0a2` 候选已完成 V3 M2 Fund Profile Data 的实现和验收，但尚未对外发布。远端 PR、CI、push 和 annotated tag 未在本轮执行；当前已发布预览版本仍是 `v3.0.0-alpha.1`。

## 候选能力

- 独立 AKShare 基金目录并集与申购状态 TTL snapshot，满足完整性/映射阈值后才原子切换。
- code-scoped 基金概况、交易规则和费率 service/cache/CLI/artifact/trace/contract。
- Fund Terminal 目录并集、申购状态筛选、服务端排序/分页和 catalog-only 稳定详情 URL。
- Product API diagnostics 隔离与“概览 / 净值与业绩 / 费率与规则”产品标签页。
- 真实参考快照 27,487 条目录、27,181 条申购状态；三类基金 profile/trading/fee artifact 均为 `updated`。

## 已知上游限制

AKShare `1.18.64` 的旧“申购费率（前端）”indicator 与当前上游标题不一致；场内 ETF 也可能没有赎回费率表。trace 保留非 critical warning，产品只展示已验证的原始费率文本，不绕过 provider、不补造缺失值。

## 发布前仍需完成

1. 获得远端交付授权并 push 当前本地集成提交。
2. 创建 PR，等待 Python 3.10/3.12 等仓库 CI 全部通过并处理 P0/P1。
3. 合并后在 clean `main` 核对版本和边界，再创建并推送 `v3.0.0-alpha.2` annotated tag。
4. 只有上述步骤完成，才把 README、Roadmap、Todo 与本报告状态改为“已发布”，并进入 M3。

## 验收与边界

完整本地证据见 [`../reviews/2026-08-12-v3-m2-fund-profile-acceptance.md`](../reviews/2026-08-12-v3-m2-fund-profile-acceptance.md)。M2 没有修改主评分、主风险、daily 默认 Provider、watchlist、portfolio 或 scheduler，也没有交易、券商、买卖建议或收益承诺。

回滚使用已发布的 `v3.0.0-alpha.1`，不删除 cache、outputs、配置或 scheduler。
