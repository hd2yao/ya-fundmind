# v3.0.0-alpha.2 Release Report

## 状态

YA FundMind OS `v3.0.0-alpha.2` 完成 V3 M2 Fund Profile Data。实现 PR #55 的 Python 3.10、Python 3.12 与 Product Web CI 全绿后已合并到 clean `main`；annotated tag `v3.0.0-alpha.2` 已推送。`v2.6.0` 仍是稳定基线，M3 ETF Market 尚未开始实现。

## 候选能力

- 独立 AKShare 基金目录并集与申购状态 TTL snapshot，满足完整性/映射阈值后才原子切换。
- code-scoped 基金概况、交易规则和费率 service/cache/CLI/artifact/trace/contract。
- Fund Terminal 目录并集、申购状态筛选、服务端排序/分页和 catalog-only 稳定详情 URL。
- Product API diagnostics 隔离与“概览 / 净值与业绩 / 费率与规则”产品标签页。
- 真实参考快照 27,487 条目录、27,181 条申购状态；三类基金 profile/trading/fee artifact 均为 `updated`。

## 已知上游限制

AKShare `1.18.64` 的旧“申购费率（前端）”indicator 与当前上游标题不一致；场内 ETF 也可能没有赎回费率表。trace 保留非 critical warning，产品只展示已验证的原始费率文本，不绕过 provider、不补造缺失值。
