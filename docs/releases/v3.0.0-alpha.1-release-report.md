# v3.0.0-alpha.1 Release Report

## 结论

YA FundMind OS `v3.0.0-alpha.1` 完成 V3 M1 Product Truth & Information Architecture。它把既有本地研究工作台收敛为更诚实、可浏览的基金与市场信息产品骨架：用户页面展示产品信息和自然语言状态，运维诊断留在结构化 trace 与系统工具中。

`v2.6.0` 仍是稳定基线；alpha 仅代表 M1 的交付完成，不代表 V3 完整功能或投资模型升级。PR #54 已通过 CI 并合并；annotated tag `v3.0.0-alpha.1` 已推送，指向 clean `main` commit `8a13d4d898f90558ae222593947d8456d10851ab`。

## M1 用户可见能力

- 市场、基金、自选、组合成为一级入口；研究、审核、系统和报告保留为二级工具。
- 新增只读自选页，明确显示它来自现有配置，不写入 `watchlist` 或 `portfolio` 文件。
- 缺失估值、净值和持仓市值保持 unknown/null，不再将缺失数据伪装为 `0`、`-100%` 或虚假权重。
- 普通产品页面不展示 provider 名、cache、raw warning code、schema 或 endpoint 错误；用户会看到数据日期、更新状态与可行动的自然语言空态。
- 行业板块行可直接选择，不需要水平拖动到隐藏动作列；涨跌使用中国市场惯例，正值红色、负值绿色，同时保留正负号。
- 行业历史先尝试既有 AKShare 东方财富 endpoint；失败时只允许 AKShare 同名 THS endpoint 回退。没有完全同名数据时保留当前行情并说明“历史日线暂未取得”，不以近似行业替代。
- 新增受控运维命令：

  ```bash
  python -m fund_agent.cli refresh-market-sector-history \
    --provider akshare --symbols BK1042,BK1036 --output-dir outputs
  ```

  该命令为每个请求板块写结构化 health 和独立 Provider Trace，不接入 daily/weekly scheduler。

## 已知限制

- 当东方财富行业日线不可用且 AKShare 中不存在完全同名板块时，该板块暂无连续历史日线。产品页会明确展示空态；该覆盖限制列入 V3 P2，禁止名称近似映射。
- M1 不接入新的基金档案、申购赎回、费率、ETF 盘口、持仓、评级或新闻 Provider；这些按 M2-M4 的独立契约逐步交付。

## 回滚

回滚不删除 `outputs/`、SQLite cache 或 scheduler：

```bash
git fetch --tags origin
git switch --detach v2.6.0
bash scripts/deploy_local_product_web.sh
bash scripts/status_local_product_web.sh
```

确认本地 Product Web、daily/weekly 状态和既有 v2.6 页面可读后，再从稳定 tag 建立独立 hotfix 分支。不要通过删除 cache 或改写历史 metadata 掩盖外部数据可用性问题。
