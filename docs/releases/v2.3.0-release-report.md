# v2.3.0 Release Report

## 结论

YA FundMind OS `v2.3.0` 发布 Fund Research Desk。该版本只改进本地市场研究工作台和现有三条允许指数的 daily cache 预热，不改变主评分、主风险、provider default、配置或 scheduler。

## 用户可见能力

- 本地 Product Web 继续运行在 `http://127.0.0.1:8768`，数据页面呈现为可浏览的 Fund Research Desk，而非 Markdown 报告堆叠。
- 行情页把交易日 `as_of` 与同步时刻 `updated_at`、缓存有效期 `expires_at`、来源、stale/fallback 并列展示。
- 运行 `PROVIDER=akshare` 的 daily ops 时，三条既有允许主指数会在独立、可失败隔离的步骤中预热历史缓存。
- 顶栏全局基金搜索和既有基金、组合、证据、审核、报告入口保持兼容；页面“重新读取”只请求本地结构化 API。

## 发布验证

- Python pytest、compileall、React Vitest、typecheck 和 production build 通过。
- 现有 JSON report、snapshot、trace、research context、evidence bundle 和 research answer contract validation 通过。
- 使用本地真实 outputs 对市场页完成 1440 / 768 / 375 Playwright 验收；交易日早于同步日时没有被标成 stale。
- Product Web、daily、weekly LaunchAgent 状态保持 installed/loaded；没有改写 scheduler 配置。

具体的命令输出、PR、CI、tag 和合并后本地服务健康检查记录在发布执行日志中；本报告只记录可复现的发布边界，不以日期伪造数据新鲜度。

## 已知限制

- 行业板块 live 端点仍可能受外部 AKShare/东方财富网络条件影响；失败以结构化 `503` 或已有 cache fallback 呈现，不伪造 live 结果。
- 本版本不增加新闻抓取、全市场历史回填、多源数据核验或公网部署。

## 回滚

回滚不删除 outputs、SQLite cache 或 daily/weekly scheduler：

```bash
git fetch --tags origin
git switch --detach v2.2.0
bash scripts/deploy_local_product_web.sh
bash scripts/status_local_product_web.sh
curl -fsS http://127.0.0.1:8768/api/health
```

确认 health、首页和市场 API 可用后，再从稳定 tag 建立单独 hotfix 分支。不要通过删除 cache 或修改历史 metadata 掩盖数据问题。

## 边界确认

- 主评分：没有修改。
- 主风险：没有修改。
- 自动交易、券商接入、买卖建议与收益承诺：没有。
- default provider、watchlist、portfolio、daily/weekly schedule：没有修改。
