# YA FundMind OS v1.3.0 Release Report

## 发布目标

完成 V2 M3 Research Copilot Core：提供受约束的自然语言研究入口、确定性只读计划、结构化 Research Answer、无 LLM 中文 renderer 和脱敏审计。

## 交付内容

- `ResearchIntent`、`ResearchPlan`、`ResearchAnswer`。
- market、fund、portfolio、news、history、quality 六类确定性 intent。
- 交易、仓位、收益承诺、推荐和自动交易请求优先拒绝。
- Query -> Evidence Bundle -> Research Answer 的只读研究链路。
- finding、evidence、质量等级和引用路径原样保留，不新增事实数值。
- 基金问题缺少 6 位代码时明确返回 `fund_code_required`，不猜测基金。
- 确定性中文 Markdown renderer；可选 renderer 只接收 JSON 深拷贝且失败时回退。
- append-only JSONL audit，问题只保留 SHA-256 和脱敏预览。
- `research-ask` CLI、`research-answer-v1` contract、validator 和文档。

## 兼容和边界

- 不改变 daily/weekly、provider 默认或 V1/M1/M2 contract 语义。
- 不修改 watchlist 或 portfolio。
- 不修改主评分或主风险。
- 不解析 Markdown/HTML。
- 默认不依赖 LLM、MCP 或网络。
- 不输出买卖建议，不自动交易，不接券商，不承诺收益。
