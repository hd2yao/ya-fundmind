# v2.6.0 Release Report

## 结论

YA FundMind OS `v2.6.0` 发布 News / Announcement Evidence Browser，并完成既定 `v2.3`–`v2.6` 本地 Product Web 交付序列。新闻/公告内容仍是已有本地 evidence，不是推荐或评分输入。

## 用户可见能力

- 在 `/news` 以文本、关联主题、来源质量和证据强度筛选已有 evidence；筛选仅在浏览器内生效，不修改 JSON artifact。
- 每条证据同时显示发布时间、来源、来源质量、强度、低置信度与原始 warnings；缺 URL 和不安全 URL 明确标记。
- 关联代码只有在本地 Fund Explorer 索引命中时才链接到 `/funds/:code`，并可以安全返回 `/news`；未索引或无效代码不提供可点击入口。
- 仅 `http/https` URL 使用新窗口打开，带 `noopener noreferrer`；fixture evidence 继续在页头显式标识。

## 发布验证

- Python Web API 测试覆盖本地索引命中/索引外代码与空/旧 artifact 的兼容性。
- React 测试覆盖四类筛选、无结果状态、已索引/未索引代码和安全 URL；typecheck 与 production build 通过。
- Playwright 在 1440 / 768 / 375 真实本地 evidence 产物上检查筛选工具栏、基金链接、低置信度和缺 URL 状态。
- Python pytest、compileall、既有 contract validation 与 Product Web dry-run 在发布门执行；daily/weekly launchd 保持不变。

## 工程边界

- 没有新增新闻/公告抓取、数据 provider、输出 contract 或外部网络请求。
- 没有修改主评分、主风险、默认 provider、watchlist、portfolio 配置或 scheduler。
- 不自动交易，不接券商，不输出买卖建议或收益承诺。

## 回滚

不删除 outputs、SQLite cache 或 scheduler：

```bash
git fetch --tags origin
git switch --detach v2.5.0
bash scripts/deploy_local_product_web.sh
bash scripts/status_local_product_web.sh
```

确认 `/news`、`/api/news` 和 `/funds/<code>` 可读取后，再从稳定 tag 建立 hotfix 分支。
