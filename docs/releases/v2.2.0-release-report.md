YA FundMind OS `v2.2.0` 完成 Fund Data Terminal 发布门禁。发布 PR 为 #40，正式 tag 在本报告合入 clean `main` 后创建。

## 用户可见能力

- 本地地址：`http://127.0.0.1:8768`
- 一级工作区：行情总览、基金终端、组合、研究证据。

## 已知外部限制

行业板块目录真实 smoke 返回 `503 market_sector_unavailable`。根因为当前环境访问东方财富行业端点时代理连接被远端关闭。该失败已保留原始结构化错误，页面会降级展示且安全换行；本发布没有伪造行业 live 成功。

本机 Node 23 不在项目声明的推荐范围，`npm ci` 会输出 `EBADENGINE` warning，但测试、typecheck 和 build 均通过；远端 Product Web CI 使用受支持的 Node 环境。后续本机切换 Node 22 LTS 作为 P2 环境优化。

## 工程交付

- `FundHistoryService`、`MarketIndexService`、`MarketSectorService` 均采用 cache-first、显式 stale fallback。
- 基金净值继续存入 `fund_navs`；指数和行业 OHLCV 存入独立 `market_series`；行业目录存入 `market_entities`。
- React 静态资源随 Python package 分发；daily 更新 JSON 后页面读取最新数据，无需重建前端。
- Product Web 继续只监听 loopback，不做公网部署。

## 边界

- 没有修改主评分或主风险。
- 没有修改 provider default、watchlist、portfolio 或 daily/weekly schedule。
- 不自动交易，不接券商，不输出买卖建议或收益承诺。
- 不做多源自动核验、公网部署、账号或云同步。

## 回滚

回滚不删除 outputs 或 SQLite cache，也不重装 daily/weekly scheduler：

```bash
git fetch --tags origin
git switch --detach v2.1.0
bash scripts/deploy_local_product_web.sh
bash scripts/status_local_product_web.sh
curl -fsS http://127.0.0.1:8768/api/health
curl -fsS "http://127.0.0.1:8768/api/funds/search?page=1&page_size=1"
```

确认 health、首页和基金搜索可用后，再决定是否从 `v2.1.0` 建立正式 hotfix 分支。若部署失败，先保留当前 launchd/logs/outputs，切回已发布 `main` 或 `v2.2.0`，重新执行 `bash scripts/deploy_local_product_web.sh`；不要通过删除 cache 或修改 scheduler 掩盖问题。
