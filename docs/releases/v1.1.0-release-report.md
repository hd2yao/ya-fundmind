# YA FundMind OS v1.1.0 Release Report

## 发布目标

完成 V2 M1 Research Data Access：为 V1 机器可读产物建立统一白名单目录、安全 loader、紧凑查询服务和稳定 contract，为后续 Evidence/Copilot 提供只读数据底座。

## 交付内容

- `ArtifactDescriptor` 和 `ArtifactCatalog`。
- report、snapshot、trace、market、fund detail、portfolio、news、ops、daily/weekly artifact registry。
- 稳定 artifact id、内容 hash、as_of/source/quality/stale metadata。
- 缺失、损坏、旧 schema、非对象 JSON 安全降级。
- 路径穿越和未登记路径阻断。
- market/fund/portfolio/news/history/quality 紧凑查询。
- `research-query` CLI。
- `research-context-v1` contract、validator 和文档。

## 兼容和边界

- 不改变 daily 默认 provider 和 daily/weekly 执行方式。
- 不修改 watchlist 或 portfolio。
- 不修改主评分或主风险。
- 不解析 Markdown/HTML。
- 不引入网络、LLM、MCP 或 Web 新依赖。
- 不输出买卖建议，不自动交易，不接券商，不承诺收益。
