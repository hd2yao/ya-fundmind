# v2.1.0rc1 Release Report

## 状态

候选实现已完成，尚未发布 tag。最终状态以 PR #32 CI、真实数据浏览器验收和本地 launchd 验收为准。

## 交付范围

- React 19 + FastAPI Product Web 正式进入 v2.1 版本轨道。
- 全市场 Fund Explorer 支持代码、名称、类型、主题、ETF、质量、排序和服务端分页。
- 单只基金详情合并市场记录和已有 enrichment，过滤本地路径和非 allowlist metadata。
- “全市场 / 我的自选”双视图明确区分搜索范围。
- 静态构建进入 `fund_agent/web_static` 并随 wheel 分发。
- 独立 launchd 服务默认监听 `127.0.0.1:8768`。

## 数据与安全边界

- 浏览器不加载全部市场记录，每次最多返回 100 条。
- 搜索 API 不接受任意 path、URL、provider 或 SQL。
- TrustedHost、loopback Origin、report allowlist 和 review canonical id 规则保留。
- 主评分、主风险、provider default、watchlist、portfolio 和 daily/weekly schedule 不变。
- 不自动交易、不接券商、不输出买卖建议或收益承诺。
