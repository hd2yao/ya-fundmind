# YA FundMind OS v1.0.3 Release Report

## 发布目标

修复 weekly launchd 自动任务在精简 `PATH` 环境中无法找到相对 `python` 命令的问题，恢复 V1 每周研究自动化。

## 变更范围

- launchd 安装器优先使用项目 `.venv/bin/python`。
- 安装前把显式 Python 命令解析为绝对可执行路径。
- daily / weekly plist 写入相同的绝对解释器路径。
- plist 渲染使用同一个已解析解释器。
- 增加项目虚拟环境默认选择的回归测试。

## 验收标准

- scheduler 测试和全量 pytest 通过。
- `python -m compileall -q fund_agent` 通过。
- weekly plist 的 `PYTHON_BIN` 为项目 `.venv/bin/python` 绝对路径。
- `launchctl` 手动触发 weekly 后退出码为 `0`。
- weekly summary、dashboard、long-horizon stability 和 ops status 可刷新。

## 边界

- 不修改主评分或主风险。
- 不改变 daily 默认 provider 代码逻辑。
- 不修改 watchlist 或 portfolio。
- 不改变 JSON 输出契约。
- 不输出买卖建议，不做自动交易，不接券商。
