# v2.2 Fund Data Terminal M3 验收记录

## 结论

`pass_with_warning`。市场页已具备 AKShare 行业板块目录、名称/`BK` 代码搜索、当前行情字段和 `1m / 3m / 6m / 1y / all` 历史日线浏览能力。目录与历史均支持新鲜缓存、live 获取、stale fallback、来源和数据质量状态。

当前开发环境访问 AKShare 东方财富行业接口时发生代理连接中断，因此真实行业 smoke 没有成功，且没有伪造成功记录。默认离线测试、缓存降级和 Product Web 三视口交互已经通过；该网络限制作为 M5 发布前需重试的环境观察项保留，不改变 M3 的功能实现结论。

本记录只代表 `v2.2 M3` 通过，不代表 `v2.2.0` 已发布。整体数据终端重组和最终发布仍按 M4-M5 继续执行。

## 数据边界

- 目录代码固定为 `BK` 加四位数字，客户端不能指定 provider 或任意 endpoint。
- 目录字段包括最新价、涨跌幅、总市值、换手率、上涨/下跌家数和领涨股票。
- 历史字段包括日期、开盘、收盘、最高、最低、成交量、成交额、涨跌幅和换手率。
- 新鲜目录或历史缓存优先；live 失败时只有本地存在缓存才允许 fallback，并显式标记 `cache:akshare`、`stale` 和 warning。
- 坏行被隔离并计入 provider health，不会阻断其他目录项或历史点。
- 研究主题与 AKShare 行业板块保持两个观察层；“同名板块”按钮只发起搜索，不声明二者等同。

## 独立审查

只读对抗式审查无 P0，发现并修复 2 个 P1：

1. `all` 原先只请求最近五年。现改为从 `19900101` 请求完整可用历史；旧缓存没有完整覆盖标记时会重新请求，fallback 只能提供部分缓存时增加 `partial_history` warning。
