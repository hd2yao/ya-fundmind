# v2.4.0 Release Report

## 结论

YA FundMind OS `v2.4.0` 发布 Fund Data Terminal & Detail。已有全市场基金搜索的“查看”动作不再只打开短暂抽屉，而是进入可复制、可返回的本地详情 URL。

## 用户可见能力

- `/funds/:code` 展示任意已索引基金的基础字段、主题、质量、缺失字段和研究边界。
- 历史净值继续支持 `1m / 3m / 6m / 1y / all`；基础数据与历史数据分别显示 `source / as_of / updated_at / expires_at / stale / fallback`。
- 基金终端的代码、名称、类型、主题、质量、ETF、排序和分页筛选持久化到 URL；详情页的返回链接保留原查询。
- 无效基金代码、索引外基金、历史缺失或低质量数据保持可恢复的错误/空/警告状态，不生成假数据。

## 发布验证

- Python pytest、compileall、React Vitest、typecheck、build 和现有 contract validation 通过。
- 真实本地产物：`021511` 详情页读取 `120` 个 `6m` 历史净值点；切换到 `1m` 后读取 `20` 个点；基础索引和历史缓存均明确显示 source 与时间元数据。
- 1440 / 768 / 375 Playwright 通过；详情页标题、图表、返回链接、新鲜度和移动单列布局可用。
- Product Web、daily、weekly launchd 保持不变；只在合并后重新部署本地 Web 代码。

## 工程边界

- 没有新增 provider、API response 字段或 output contract。
- 没有修改主评分、主风险、默认 provider、watchlist、portfolio 或 scheduler。
- 不自动交易，不接券商，不输出买卖建议或收益承诺。
