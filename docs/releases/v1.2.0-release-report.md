# YA FundMind OS v1.2.0 Release Report

## 发布目标

完成 V2 M2 Evidence & Citation：把 M1 Research Context 转换为有原始 artifact、content hash 和 JSON Pointer 引用的 Evidence Bundle，并建立统一质量/冲突 gate。

## 交付内容

- `EvidenceRef`、`ResearchFinding`、`EvidenceBundle`。
- RFC 6901 JSON Pointer escape/resolve。
- immutable evidence id：包含 artifact id、content hash、pointer 和 claim type。
- context 与 artifact content hash 不一致时拒绝引用。
- market/fund/portfolio/news/history/quality finding builders。
- fallback/warning/legacy/insufficient/stale/degraded/critical quality gate。
- 跨来源同 claim 不同值 conflict gate。
- `build-research-evidence` CLI。
- `evidence-bundle-v1` contract、validator 和文档。

## 真实输出验证

基于 2026-07-12 本地 outputs：

- market：9 findings / 9 evidence，quality `warning`，原因是市场样本 warning。
- fund `021511`：14 findings / 14 evidence，status `partial`，缺失字段明确进入 data gaps。
- portfolio：6 findings / 6 evidence，quality `warning`，保留当前组合估值 warning。
- news：6 findings / 6 evidence，quality `warning`，保留 low-confidence warning。
- history：1 finding / 1 evidence，status `partial`、quality `warning`，最新 snapshot 缺少 delta；旧 critical snapshot 不再污染最新证据质量。
- quality：8 findings / 8 evidence，真实引用 report/trace/ops/daily/long-horizon。
- 所有 bundle 通过 contract validation；抽样 pointer round-trip 与原 artifact 值一致。
