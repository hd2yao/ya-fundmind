# v2.2.0 M4 数据终端界面验收

## 结论

M4 通过本地功能、构建和三视口验收，可以进入 M5 发布收口。

本 Milestone 只修改 Product Web 的信息架构、导航、搜索跳转和视觉密度，没有修改主评分、主风险、daily 默认 provider、watchlist、portfolio 或 scheduler。

## 已交付

- `/` 重定向到 `/market`，原运行总览迁移到 `/status`。
- 一级数据工作区为行情总览、基金终端、组合、研究证据。
- 研究助手、人工审核、系统状态和报告中心保留为辅助入口。
- 顶栏全局搜索提交到 `/funds?q=<query>`，复用既有服务端全市场搜索。
- 行情页提供主要指数、行业板块、主题窗口和趋势验证锚点。
- 指标区、数据表、图表和内容分区使用紧凑、扁平的数据终端布局。

## 自动验证

- React：12 个测试文件，36 个测试通过。
- TypeScript：`npm run typecheck` 通过。
- Production build：`npm run build` 通过，静态资源已写入 `fund_agent/web_static/`。
- `git diff --check` 通过。

## 浏览器验收

使用隔离 Product Web `http://127.0.0.1:8771` 和主线真实 `outputs/` 验证：

- 1440 x 1000：分组侧栏、全局搜索、行情图表和基金终端正常。
- 768 x 1024：抽屉导航入口、搜索栏和两列指标正常。
- 600 x 900：顶栏切换为两行且无状态徽标溢出。
- 375 x 812：搜索栏独占第二行，单列指标和图表容器正常。
- 三个视口的 `documentElement.scrollWidth === clientWidth`。
- 全局搜索 `510300` 进入 `/funds?q=510300`，返回“沪深300ETF华泰柏瑞”。
- 基金详情读取 120 个历史净值点，保留来源、日期和质量状态。
- 页内锚点不会被 sticky 顶栏遮挡；移动抽屉支持 `Escape`、焦点循环和关闭后焦点恢复。

## 已知外部限制

AKShare 行业板块目录在当前网络环境返回结构化 `503`，根因仍是东方财富上游代理连接中断。页面显示可解释的降级状态，长错误文本已经安全换行，不再造成页面横向溢出。本验收没有伪造行业 live 成功。

## 边界

- 不构成买卖建议，不承诺收益。
- 不接券商，不自动交易。
- 不把新增历史序列接入主评分或主风险。
- 不做公网部署或多源自动核验。
