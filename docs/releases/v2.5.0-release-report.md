# v2.5.0 Release Report

## 结论

YA FundMind OS `v2.5.0` 发布 Portfolio Workbench。组合页现在是对现有 `portfolio` JSON 的只读核对入口，而不是把缺失估值包装成可操作的组合结论。

## 用户可见能力

- 持仓表中的有效六位基金代码和名称可进入已有 `/funds/:code` 详情；详情页可安全返回 `/portfolio`。
- 主题暴露和基金类型暴露同时展示。可靠估值存在时使用可访问的比例条与百分比；任一组合估值缺口存在时显示“权重待估值”和 `--`。
- 当前值、收益率和权重不会从占位 `0` 或 `-100%` 推导展示；配置持仓数量和观察性问题保持可见。

## 发布验证

- React 组合页和详情回链测试通过，覆盖缺估值、可用估值、主题/类型权重、组合返回路径与空问题状态。
- React typecheck、生产 build、Python pytest、compileall 和现有 contract validation 在发布门执行。
- Playwright 在 1440 / 768 / 375 三视口检查组合页；真实本地产物显示 3 个待估值持仓、主题/类型待估值状态和持仓详情链接。
- Product Web 合并后重新部署；daily/weekly launchd 保持不变。

## 工程边界

- 没有修改主评分、主风险、默认 provider、watchlist、portfolio 配置或 scheduler。
- 没有新增 provider、持仓估值来源、输出 contract、调仓动作、交易、券商接入、买卖建议或收益承诺。
