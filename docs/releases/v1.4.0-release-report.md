# YA FundMind OS v1.4.0 Release Report

## 发布目标

完成 V2 M4 Read-only Skill / MCP：让外部工具通过受控的 status、catalog、query、ask、evidence 五个接口使用本地 Research Copilot，同时保持 optional、只读、可审计和无网络默认测试。

## 官方 SDK 选择

- 核对日期：2026-07-13。
- 官方 MCP Python SDK `main` 为 v2 beta，仍可能发生破坏性变化。
- 本项目采用官方稳定 v1.x，依赖固定为 `mcp>=1.28.1,<2`。
- 默认 transport 为本地 stdio；Streamable HTTP 仅显式选择时启用。
- optional integration 使用官方 in-memory client，不访问网络。

## 交付内容

- framework-independent `ResearchMcpAdapter`。
- `McpToolResult`、`McpAdapterError` 和五个 tool allowlist。
- topic、code、artifact type、limit、question 参数白名单。
- 任意 path、output_dir、config、write、command、URL 和未知工具拒绝。
- async timeout、safe error taxonomy 和 append-only MCP audit。
- question hash/脱敏预览；token、password、API key、Bearer、Cookie 和未知参数名不落盘。
- optional FastMCP server、stdio/Streamable HTTP transport 和 `mcp-server` CLI。
- `mcp-tool-result-v1` contract 和 validator。
- 仓库内 `skills/ya-fundmind-research/`，未全局安装。
- modern setuptools package discovery 修复；CI 改为安装 `.[dev]` 后测试。

## 兼容和边界

- 无 MCP 依赖时 V1、M1-M3 和默认 CI 正常。
- 不改变 daily/weekly、provider 默认、watchlist、portfolio 或 scheduler。
- 不修改主评分或主风险。

- 不提供通用文件系统、shell、URL fetch 或写工具。
