# YA FundMind OS v1.5.0 Release Report

## 发布目标

完成 V2 M5 Copilot Console：把 Research Copilot、证据引用、数据质量、人工审核和脱敏 audit 整合进本地 Streamlit Console，同时保留 V1 页面和只读研究边界。

## 交付内容

- 新增 `Copilot` 导航与问题表单，支持示例问题和自定义问题。
- Web 与 CLI 共用 `ResearchCopilot` 和 `write_research_answer_outputs`，不复制查询或证据规则。
- 展示 answer status、intent、as_of、confidence、review_required 和 evidence count。
- 每个 finding 可展开查看 source、as_of、quality、stale、artifact path、JSON Pointer 和 excerpt。
- 集中展示 data gaps、quality warnings 和最近脱敏 research audit。
- 覆盖 answered、empty、partial、unavailable、refused、unsupported 和 runtime error 状态。
- Home、Market、Funds、Portfolio、News、Review、Reports 改为结构化摘要；大型 JSON 只显示计数和有限预览。
- Review 页面保留原有状态写入，新增摘要指标、队列和已审核状态预览。
- 修复默认 review state 没有跟随 `--output-dir` 的启动路径问题。
