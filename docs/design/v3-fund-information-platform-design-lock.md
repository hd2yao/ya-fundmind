# V3 Fund Information Platform Design Lock

## 设计决定

V3 不再把页面设计成“自动生成报告的目录”，而是一个专业、安静、数据密集的基金信息平台。

视觉上采用 **Market Ledger / 基金行情册**：白色数据画布、深墨导航、受控的翡翠绿强调、清晰的涨跌语义色和高密度表格。它应接近基金数据终端而不是券商下单终端，不使用营销 hero、玻璃拟态、渐变光球或卡片墙。

## 任务模型

### 核心用户

本地运行项目的基金/ETF 个人研究者。

### 高频任务

1. 看今天主要指数和板块变化。
2. 按代码、名称、类型搜索任意基金。
3. 进入单只基金，查看完整档案和历史。
4. 查看自选基金今天发生的变化。
5. 对 ETF 查看成交、IOPV 和折溢价。
6. 对开放式基金查看净值、申赎状态和费率。
7. 查看组合数据缺口，而不是被误导性数值干扰。

### 次级任务

- 查看证据、Copilot、人工审核和历史报告。
- 查看 provider、cache、fallback、contract 和 scheduler。

### 非目标

- 下单、交易账户、买卖按钮。
- 推荐榜、收益承诺、刺激性涨跌动效。
- 普通页面展示 stack trace、schema 名和内部 warning code。

## 信息模型

### 用户层必须显示

- 数据对应日期。
- 最新净值或 ETF 最新价。
- 基金类型和是否场内交易。
- 收益窗口和曲线。
- 基金规模、公司、经理、成立日期。
- 申购/赎回状态和主要费率。
- 数据缺失时的自然语言说明。

### 诊断层才显示

- `source=cache:akshare`
- `provider_version`
- `schema_version`
- `expires_at`
- `fallback_reason`
- `missing_position_valuation`
- `nav_history_summary`
- 原始 exception

用户层可以显示“数据来自 AKShare，日期 2026-07-27”，但不显示内部序列化值。

## 导航模型

### 一级导航

- 市场
- 基金
- 自选
- 组合

### 二级导航

- 研究
- 报告
- 系统

### 顶栏

- 全局基金搜索
- 当前数据日期
- 自选入口
- 数据状态图标

“本地运行”“只读研究”不再以两个常驻 badge 占据顶栏；边界说明放在关于页和首次空态。

## 页面布局

### 市场

```text
[指数摘要带：上证 / 沪深300 / 创业板 / 成交额]
[主指数大图 2/3] [板块涨跌分布 1/3]
[行业板块榜单 1/2] [ETF 活跃榜 1/2]
[数据说明]
```

### 基金库

```text
[搜索 + 类型 + 场内/场外 + 可申购 + 排序]
[结果总数 / 数据日期]
[高密度基金表]
[分页]
```

表格列默认不超过 9 个：代码、名称、类型、净值/价格、日涨跌、近 1 月、近 1 年、规模、状态。更多字段进入列设置或详情。

### 基金详情

```text
[返回 / 名称 / 代码 / 类型 / 自选状态]
[关键指标带]
[标签页导航]
[主内容 2/3] [资料摘要 1/3]
```

首屏必须明确区分：

- ETF：最新价、成交额、折溢价、行情时间。
- 开放式基金：单位净值、净值日期、申购/赎回状态。

### 自选

- 不重复“全市场”宣传；明确标为“AKShare 基金库”。
- 显示自选数量、最新数据日期和最近变化。
- 每行进入同一基金详情。
- V3 第一版只读 `configs/watchlist.yaml`；页面编辑配置不是 M1 必做。

### 组合

- 缺失当前估值时显示“暂不可计算”，不显示 0 元和 -100%。
- 将持仓配置、估值状态、主题暴露和风险观察分区。
- 不显示调仓按钮和建议动作。

## 视觉系统

### 色彩

- 导航背景：`#102521`
- 主文字：`#17211E`
- 次文字：`#5F6E68`
- 页面画布：`#F5F7F6`
- 数据表面：`#FFFFFF`
- 主强调：`#087F6F`
- 正向：`#C33B32`
- 负向：`#168B63`
- 警告：`#9A6700`
- 边框：`#D8E0DC`

涨跌颜色遵循中国市场习惯，但所有状态同时提供符号或文字，不只靠颜色。

### 排版

- 中文系统字体；数字使用 tabular numbers。
- 页面标题 24–30px；紧凑面板标题 16–20px。
- 不使用随 viewport 变化的字体尺寸。
- 字间距为 0。

### 形状

- 圆角 4–8px。
- 页面 section 不做漂浮卡片。
- 单个重复项目和弹窗可使用卡片。
- 图表为无装饰数据画布，不放在套娃卡片中。

### 图标

- 使用 Lucide。
- 搜索、收藏、筛选、列设置、刷新、返回使用图标按钮并带 tooltip。
- 只有明确命令使用图标 + 文本。

## 状态模型

| 内部状态 | 用户文案 | 展示位置 |
| --- | --- | --- |
| `normal` | 数据已更新 | 顶栏数据状态 |
| `stale` | 当前展示缓存数据，日期为… | 页面状态条 |
| `fallback` | 实时更新失败，已使用最近缓存 | 页面状态条 |
| `partial` | 部分资料暂缺 | 对应资料区 |
| `missing_position_valuation` | 当前估值暂不可用 | 组合行 |
| `fixture` | 示例数据，不代表当日真实内容 | 演示页；正式导航默认隐藏 |

详细 code、endpoint 和 error 进入系统页。

## 响应式模型

### 1440px

- 232px 固定侧栏。
- 内容最大宽度 1760px。
- 市场主图与辅助榜单使用 2:1。
- 基金详情使用 2:1。

### 768px

- 侧栏变抽屉。
- 顶栏搜索占主宽。
- 双栏改为单列。
- 表格横向滚动并固定代码/名称列。

### 375px

- 底部或抽屉导航。
- 搜索为单独入口。
- 指标带横向滚动。
- 基金详情标签页横向滚动。
- 不强行把桌面表格压缩为不可读卡片；使用精选列 + 详情。

## Design Health

| 维度 | 目标 |
| --- | --- |
| 层级 | 4/4，基金浏览为明确主线 |
| 信息 | 4/4，关键基金资料可定位 |
| 任务 | 4/4，市场/搜索/详情/自选闭环 |
| 交互 | 3/4，筛选和详情完整，配置编辑后置 |
| 数据真实性 | 4/4，unknown 不变 0 |
| 诊断隔离 | 4/4，普通页面无内部 code |

## 验收

- [ ] 首页不是报告摘要，而是市场和基金入口。
- [ ] 全局搜索可到任意基金详情。
- [ ] 基金详情按基金类型显示不同字段。
- [ ] 用户页面不存在内部字段名和 warning code。
- [ ] fixture 新闻不会伪装为正式新闻。
- [ ] 缺失估值不会显示 0 元或 -100%。
- [ ] 1440 / 768 / 375 真实浏览器无重叠和页面级溢出。
- [ ] keyboard、focus、label、对比度通过基本 accessibility 检查。
- [ ] 页面事实来自结构化 API，不解析 Markdown。
