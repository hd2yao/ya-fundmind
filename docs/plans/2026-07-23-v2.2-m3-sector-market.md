# YA FundMind OS v2.2 M3 行业板块行情实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在本地 Product Web 中提供可搜索、可点击的 AKShare 行业板块目录和 `1m / 3m / 6m / 1y / all` 历史日线，同时保持主评分、主风险和 daily 默认流程不变。

**Architecture:** 行业板块目录使用独立的 `market_entities` SQLite 表保存代码、名称和当前行情字段；历史 OHLCV 继续复用 `market_series`，但固定 `series_type="industry"`。`MarketSectorService` 统一执行 cache-first、live fetch、stale fallback、分页搜索和质量标记，FastAPI 只暴露固定参数边界，React Market 页通过目录搜索选择板块并复用市场曲线组件。

**Tech Stack:** Python 3.10+、dataclass、SQLite、AKShare、FastAPI、React、TypeScript、Recharts、pytest、Vitest、Testing Library、Playwright。

---

## 范围与边界

- 仅接入 AKShare 东方财富行业板块目录与行业板块历史日线。
- 目录字段包括板块代码、名称、最新价、涨跌幅、总市值、换手率、上涨/下跌家数和领涨股票。
- 历史序列字段包括日期、开盘、收盘、最高、最低、成交量、成交额、涨跌幅和换手率。
- 不把行业板块数据接入主评分、主风险、推荐、交易或收益承诺。
- 不把现有基金主题强制映射为行业板块；名称不完全一致时保持两个观察层独立。
- 默认 pytest、Vitest 和 CI 不访问真实网络；真实 AKShare 只做手动 smoke。
