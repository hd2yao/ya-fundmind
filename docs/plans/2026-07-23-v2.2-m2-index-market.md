# v2.2 M2 指数走势实施计划

## 目标

在现有市场情报页增加主要指数的真实日线观察能力，支持上证指数、沪深 300、创业板指的按需历史曲线。指数 OHLCV 使用独立市场时间序列表，不复用基金净值缓存。

## 数据范围

| symbol | 名称 | AKShare 主接口 | 同源降级接口 |
| --- | --- | --- |
| `000001` | 上证指数 | `stock_zh_index_daily_em` | `stock_zh_index_daily` |
| `000300` | 沪深300 | `stock_zh_index_daily_em` | `stock_zh_index_daily` |
| `399006` | 创业板指 | `stock_zh_index_daily_em` | `stock_zh_index_daily` |

窗口采用有效交易点：`1m=20`、`3m=60`、`6m=120`、`1y=240`、`all=全部`。
首次按需请求最多抓取最近五年，并只将请求日期范围内的有效点写入市场序列缓存。主接口不可用或返回无效数据时，允许在 AKShare provider 内切换到新浪指数端点；这属于可用性降级，不代表多源核验，端点 trace 和 `endpoint_fallback` warning 必须保留。

## 实施单元

1. 新增 `MarketSeriesPoint` 与 SQLite `market_series` 表，覆盖 OHLCV、成交额、涨跌幅、来源和新鲜度。
2. 为 `AkshareProvider` 增加指数日线映射，复用 timeout/retry/静默和 Provider Health。
3. 新增 cache-first `MarketHistoryService`，支持 live、fresh cache、stale fallback 和可解释失败。
4. 新增固定 allowlist API：`GET /api/market/indices/{symbol}/history?range=6m`。
5. 市场页新增指数切换、窗口切换、真实曲线、摘要和数据表。

## 验收标准

- 默认 pytest 不访问网络。
- 指数 live 成功后写入独立缓存，第二次请求命中新鲜缓存。
- 非 allowlist symbol 和非法窗口被拒绝。
- live 失败时可使用 stale cache；无缓存时返回清晰 503。
- 页面展示 `source/as_of/stale/fallback/data_quality_grade`。
- Python pytest/compileall、React test/typecheck/build 和 contract validation 通过。
- AKShare 可用时完成至少一个指数真实 smoke。
- 主评分、主风险、daily 默认 provider、watchlist、portfolio 和 scheduler 不变。

## 非目标

- 不接入更多指数或分钟级行情。
- 不做多源核验。
- 不把指数走势接入评分、风险或推荐。
- 不做交易、券商接入或收益承诺。
