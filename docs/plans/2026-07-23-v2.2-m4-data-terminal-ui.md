# YA FundMind OS v2.2 M4 数据终端界面计划

## 目标

把 Product Web 从“报告章节导航”收敛为本地基金数据终端。用户打开根路径后直接进入行情总览，可以从任意页面全局搜索基金；组合与研究证据保持独立工作区，运行状态、审核和报告退到辅助入口。

本 Milestone 只重组前端信息架构、导航、页面密度和跨模块跳转，不新增数据源，不修改主评分、主风险、daily provider、watchlist、portfolio 或 scheduler。

## 设计契约

### 任务模型

- 用户场景：在本机快速浏览行情、搜索基金、查看持仓和核对研究证据。
- 主要任务：查看市场/基金数据并进入单只基金历史。
- 主操作：切换数据工作区、全局搜索基金、选择指数/板块/基金。
- 次操作：研究助手、人工审核、系统状态和报告查看。
- 非目标：营销首页、推荐、交易、券商、复杂 Web 管理后台。

### 信息模型

- 一级工作区：行情总览、基金终端、组合、研究证据。
- 辅助研究：研究助手、人工审核。
- 系统工具：系统状态、报告中心。
- 顶栏必须显示当前工作区、全局基金搜索、本地/只读状态。
- 页面继续展示 source、as_of、quality、stale/fallback 和研究边界。
- loading、empty、error、success 状态必须保留。

### 布局与几何

- 桌面：208px 固定分组侧栏，68px 顶栏，内容宽度最大 1600px。
- 顶栏：左侧当前工作区，中间全局基金搜索，右侧本地/只读状态。
- 行情页：页内导航串联主要指数、行业板块、主题窗口和趋势验证。
- 基金页：接收顶栏 `q` 查询参数并直接执行服务端全市场搜索。
- 960px 以下使用现有可访问抽屉导航；640px 以下顶栏搜索独占一行。
- 表格只允许局部横向滚动，页面根节点不得横向溢出。

### 风格与 Design Lock

- 风格：专业、安静、高密度的行情数据终端。
- 颜色：深绿黑导航、白/浅灰数据表面、青绿主状态、蓝色链接、红色负值。
- 组件：平面分区、连续指标条、紧凑工具栏、清晰曲线和表格。
- 主要数据区圆角不超过 6px，既有状态组件不超过 8px；减少阴影，不使用渐变、装饰球或营销式大标题。
- 保留现有 Inter/系统中文字体、Lucide 图标和语义色。

## 实施任务

### Task 1：分组导航与根路径

- 将四个数据工作区设为一级导航。
- 将研究助手/审核与系统状态/报告分组为辅助导航。
- 根路径重定向到 `/market`，原研究总览迁移到 `/status`。
- 保留所有既有功能路由和 404 恢复入口。

### Task 2：全局基金搜索

- 在顶栏增加代码/名称搜索。
- 提交后跳转 `/funds?q=<query>`。
- `FundsPage` 读取 URL 查询参数并执行现有服务端搜索。
- 空搜索跳转基金终端默认列表，不创建新搜索 API。

### Task 3：数据终端视觉层级

- 收紧 PageHeader、指标、内容区和表格密度。
- 指标区改为连续数据条，不再呈现为独立装饰卡片。
- 行情页增加页内数据导航与明确的区域锚点。
- 更新中文命名：市场情报 -> 行情总览，基金探索 -> 基金终端，新闻证据 -> 研究证据。

### Task 4：测试与视觉验收

- 更新 AppShell、App、Funds、Market 页面测试。
- 覆盖根路径、导航分组、全局搜索和 URL 查询同步。
- 运行 Python pytest/compileall/contract 和 React test/typecheck/build。
- 使用 Product Web 新鲜构建在 375/768/1440 验收导航、搜索、行情和基金跳转。
- 记录 console error、页面横向溢出、长名称和错误状态。

## 验收标准

- 打开 `/` 直接到行情总览。
- 一级导航只有四个数据工作区，辅助入口分组清楚。
- 任意页面可以用顶栏搜索基金并进入基金终端结果。
- 行情页主要指数、行业板块、主题和趋势区域可快速跳转。
- 所有旧功能仍可访问，现有结构化 API 不变。
- 三视口无整体横向溢出，键盘焦点和移动导航可用。
- 不修改主评分、主风险、daily 默认 provider、watchlist、portfolio 或 scheduler。
- 不输出买卖建议，不做交易或收益承诺。
