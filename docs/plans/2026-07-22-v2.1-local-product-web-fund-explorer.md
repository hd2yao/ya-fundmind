# YA FundMind OS v2.1 Local Product Web + Fund Explorer Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改变 daily 默认行为、主评分和主风险的前提下，交付可由 launchd 常驻运行的本地 Product Web，并让用户能够在真实全市场产物中搜索、筛选和查看基金详情。

**Architecture:** FastAPI 只读 API 在服务端加载并缓存 `market_intelligence_report.json` 的基金记录和主题分类，提供分页搜索与详情接口；React 19 前端消费 API，使用“全市场 / 我的自选”双视图和详情抽屉完成浏览。独立 launchd 服务只监听 `127.0.0.1:8768`，daily 更新 JSON 后无需重建前端。

**Tech Stack:** Python 3.10+、FastAPI、Uvicorn、Pydantic、React 19、TypeScript、Vite、React Router、Recharts、Lucide React、Vitest、Testing Library、Playwright、launchd。
