# V3 M1 行情页产品化收口

## 目标

将“行情总览”从工程产物浏览页收口为基金信息平台的市场入口。页面只服务指数、行业板块和主题观察；缓存、provider、原始质量码和运行实现细节保留在“系统状态”，不进入常规浏览路径。

## 本批范围

1. 统一中国市场视觉语义：上涨为红色、下跌为绿色、零值中性。
2. 将数据状态翻译为可理解的中文提示；常规页面不显示 `source`、`cache`、`normal`、`warning`、`stale` 等原始字段。
3. 让行业板块表格整行可选，固定板块识别列，减少横向滚动和隐藏操作。
4. 移除只重复主题表格的详情抽屉；近期变化列表改为可操作的板块检索入口。
5. 从行情页移除数据质量趋势图，仅在系统状态页保留运行与质量诊断职责。
6. 用共享 shell 与新鲜度组件清除“本地 / SQLite / JSON / 本机运行”等实现措辞，避免其他用户页面继续暴露同类诊断信息。

## 非目标

- 不改变 API、Provider、缓存、每日运行、主评分或主风险。
- 不增加推荐、交易或收益承诺。
- 不在本批实现基金档案、更多数据源或系统状态页改版。

## 验收

- 普通行情页看不到 provider、缓存、原始质量码和本机实现文字。
- 最新交易日期和更新时间仍清楚可见；异常时使用中文、面向用户的提示。
- 指数、板块行、时间窗口和“近期变化”均可操作；板块行无需先水平滚动到右侧。
- 指数及板块涨跌颜色遵循涨红跌绿；tooltip 显示日期、收盘和涨跌幅。
- `质量趋势` 不再出现在行情页。
- 375px、768px、1440px 无根页面横向滚动、关键文本裁切或重叠。
- 前端测试、构建及既有 Python 测试保持通过。

## 回滚

本批只涉及前端展示和文档。回滚对应 Git commit 即可恢复，不会改变输出文件、缓存或调度任务。
