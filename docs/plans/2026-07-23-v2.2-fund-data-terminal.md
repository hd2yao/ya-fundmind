# YA FundMind OS v2.2 Fund Data Terminal Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在保留全市场基础索引的前提下，交付“搜索基金 → 点击详情 → 按需获取历史净值 → SQLite 缓存 → 前端曲线”的第一条数据终端闭环，并为指数和板块序列预留清晰边界。

**Architecture:** 新增 `FundHistoryService` 负责 cache-first、AKShare live fetch 和 stale fallback；`AkshareProvider` 只负责调用和规范化，`FundCache` 负责来源隔离后的历史点存取。FastAPI 提供受限历史接口，React 详情抽屉使用 Recharts 展示可切换窗口的净值曲线。

**Tech Stack:** Python 3.10+、SQLite、AKShare、FastAPI、React 19、TypeScript、Recharts、Vitest、pytest。

- 不修改主评分、主风险和 daily 默认 provider。
- 默认测试不得访问真实网络。
- 新增接口必须只接受规范化代码和固定窗口。
- 任何 live 失败都必须显式返回错误或 stale fallback，不能伪造数据。
- 如果 AKShare 历史接口字段与 mock 假设不一致，先更新映射测试和本文档，再继续前端接入。
