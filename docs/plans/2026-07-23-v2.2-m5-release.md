# YA FundMind OS v2.2 M5 发布收口计划

## 目标

将 M1-M4 已验收的 Fund Data Terminal 正式发布为 `v2.2.0`。本 Milestone 只做版本统一、完整回归、发布证据、PR/CI、tag、本地部署和回滚检查，不新增数据源或业务功能。

## 发布内容

- 任意已索引基金的按需历史净值与 cache-first/stale fallback。
- 上证指数、沪深 300、创业板指历史日线。
- 行业板块目录、搜索、历史日线和主题同名搜索桥。
- 行情总览、基金终端、组合、研究证据四个一级工作区。
- 全局基金搜索、紧凑数据终端布局和移动端可访问导航。

## Task 1：版本与文档

- 将 `pyproject.toml` 和 `fund_agent/__init__.py` 统一为 `2.2.0`。
- 更新 README、CHANGELOG、V2 roadmap 和 backlog。
- 新增 `docs/releases/v2.2.0-release-report.md`。
- 记录行业 AKShare live smoke 的真实结果，不得把网络失败写成成功。

## Task 2：完整验证矩阵

- Python：`python -m pytest -q`、`python -m compileall -q fund_agent`。
- React：`npm test -- --run`、`npm run typecheck`、`npm run build`。
- Contract：`validate-contract --output-dir outputs`。
- Product Web：`product-web --dry-run`、结构化 API、全局搜索和基金详情 E2E。
- 浏览器：375 / 600 / 768 / 1440，无页面级横向溢出。
- Ops：Product Web、daily、weekly LaunchAgent 状态不回归。

## Task 3：真实数据与降级验证

- 复核全市场基金覆盖数和 `as_of`。
- 复核基金历史与指数历史的 live/cache 状态。
- 尝试真实行业目录 smoke；若上游仍不可用，保留结构化 `503`、trace/错误证据和页面降级状态。
- 不复制历史日期，不伪造 live row，不修改既有运行 metadata。

## Task 4：远端交付

- 分支提交后创建 PR，等待 Python 3.10、Python 3.12 和 Product Web CI。
- P0/P1 清零后合并。
- 在 clean `main` 上部署本地 Product Web 并完成 post-merge smoke。
- 创建并推送 annotated tag `v2.2.0`。

## 回滚

- Web 服务代码回滚到 `v2.1.0`；本地 outputs 和 SQLite cache 不删除。
- `bash scripts/deploy_local_product_web.sh` 重新构建并重启常驻服务。
- daily/weekly scheduler 不属于本次变更，不需要重装。

## 发布 Gate

- 所有默认离线测试、编译、contract 和前端构建通过。
- Product Web health、首页、全局搜索、基金详情和指数曲线可用。
- 已知行业上游失败必须可解释降级，不能破坏其他工作区。
- main 工作区 clean，版本文件一致，PR CI 通过。
- 主评分、主风险、provider default、watchlist、portfolio 和 scheduler 无修改。
- 不自动交易，不接券商，不输出买卖建议或收益承诺。
